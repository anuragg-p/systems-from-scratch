# Module 08 - Network

A network card driver, Ethernet and ARP, IPv4 and UDP, sockets, and a DNS lookup whose answer comes from outside the machine. It stands on the disk driver's virtqueues (05.01), sleep and wakeup (04.03) and open files (05.07); nothing in the rest of the kernel depends on it.
