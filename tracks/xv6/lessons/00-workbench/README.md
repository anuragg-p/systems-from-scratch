# Module 00 - The workbench

The whole kernel in one picture, before any part of it is built: 00.01 follows one `ls` from the shell down to the disk and back, and then turns to the cross compiler, the QEMU virt machine, and the linker script that puts the kernel at 0x80000000. 00.02 shows how to run and debug the kernel on it.
