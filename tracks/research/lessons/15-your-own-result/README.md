# Module 15 - Your own result

This module does one small piece of research whole, on a question the track's own results left: 08.03 found that a GPT of one block without positions cannot see the order of its window, that from the second block on the causal mask lets order in, and that at four blocks learned positions were worth 0.065 bits per character; so what are they worth as blocks are added, and how many blocks does a GPT without them need to match one with them? It chooses the question from a list of the track's surprises by what a laptop can settle in an hour, searches what is published (deep models without positions do about as well; nobody found measured it block by block from one block up), makes it small, writes seven predictions with a rule for each and commits them before anything runs, and runs a pilot whose spread fixes 22 pairs of seeds. The experiment, 47 minutes of CPU, gives each model its own search of the learning rate and pairs every run: positions are worth 0.288 bits at one block and less at every block added, 0.124 at eight, never 0, and no depth without them reaches one block with them; the same number of weights put elsewhere closes none of the gap. Six predictions held; the seventh failed, and that is the finding: at four blocks positions are worth 0.201 bits, three times 08.03's, because 08.03 gave both models one rate and the model with positions gains far more from a larger one. Another held for a reason it did not give, and pairing, which made 13.02's interval a quarter narrower, bought nothing here. Then the paper, written by a script from the logs so that no number is typed by hand and read against Peyton Jones's advice, and the repository: every run's settings and seed kept, the data pinned and its licence recorded, one command per figure, the recorded commands making the same bytes again in a new folder, no weights shipped, and a checklist for publishing a result of your own. It stands on module 08's GPT, module 13's fair search, paired seeds and held-out texts, and module 14's predictions written before the runs. After it the learner has done research end to end, from a question to a result someone else can rerun.
