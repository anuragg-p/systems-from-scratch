# Module 08 - The transformer: a GPT

Module 07 ended with attention looking from one sequence into another; this module turns it onto one sequence and builds a GPT from it, in one file the rest of the track starts from. Every position of a window asks every position before it, with the scores divided by the square root of their length, as Vaswani et al.'s footnote says they must be, and a mask that hides everything later: without the mask the model's loss looks better and, asked honestly, it is far worse and writes one letter over and over. Attention stacked four deep the obvious way is far worse than one layer; on a residual stream, with layer norm and an MLP in each block, four blocks beat one, and four heads beat one head of the same size only barely beyond the noise. Without positions a GPT of one block gives the same guess for any order of what came before, exactly; from two blocks on the mask itself lets order in, as Haviv et al. found at scale, and learned positions add 0.065 bits. Trained for a minute, the GPT is only below the count of pairs. The module's long run, 2.7 million weights for 56 minutes, two seeds each way, shows Vaswani et al.'s point about dropout: without it the held-out curve turns up two thirds of the way through, with it the curve is still falling, and both seeds end at 2.216 and 2.237 bits per character, below everything module 07 built. Last, the sampler: greedy loops, as Holtzman et al. found, but on characters their nucleus is no closer to the real text than plain sampling, and the long run's model finds even its plain samples likelier than Shakespeare. It stands on module 03's AdamW and schedule, module 04's layer norm and residual connections, module 05's dropout and three sets, and module 07's text, ladder and attention. After it the track has a GPT it trained, a checkpoint that loads, and a way to write with it.
