# Module 07 - Building in order: make

This module builds make, which reads a makefile and builds what it says, each thing after what it needs; its real input is this track's own Makefile, every tool's part of it included, and by the end its `-n` prints the same bytes as the system's make, and it can build the track in place of the system's make. It reads the makefile into a graph, a node for each name, found through module 01's hash table, and builds it first by the obvious recursion, which gets the order right and makes a thing once for every path to it: 482 commands for the track where 86 will do, a build left out of date behind it, and over a minute for twelve diamonds stacked one under another. Depth-first search marks each node new, open or done, so it enters each node once and finds a cycle the moment it meets an open node, naming every target on it, where GNU make drops an edge and carries on. The order in which the search finishes the nodes is a topological order, and one pass along it, comparing the files' modification times, makes each target once and only when it is out of date: after a change to one library file, the same 24 commands as the system's make, and nothing when nothing has changed. Last, a count of each target's unfinished prerequisites and a queue of the targets that are ready run independent recipes side by side: the track from nothing in under half a second with `-j 8`, where one recipe at a time takes two and a half. It stands on module 01's growable array and hash table, and adds a queue to the library.
